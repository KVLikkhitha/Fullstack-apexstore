#  ApexStore — Full-Stack E-Commerce Web App

A full-stack e-commerce web application with a shopping storefront and an admin dashboard.

---

##  Live Demo

- **Live Storefront Link**: [https://apexstore-frontend-two.vercel.app/](https://apexstore-frontend-two.vercel.app/)
- **Frontend Hosted On**: Vercel
- **Backend Hosted On**: Render
- **Database**: MongoDB Atlas

---

##  Tech Stack

- **Frontend**: React, Vite, TypeScript, SCSS
- **Backend**: Node.js, Express, TypeScript
- **Database**: MongoDB (Mongoose)

---

## ✨ Features

- **Storefront**: Browse products, category filter, price slider, and search.
- **Cart & Wishlist**: Add/remove items, manage quantities, and apply coupon codes.
- **Admin Dashboard**: View sales statistics, manage products, view orders with status filters, and check low stock alerts.

---

##  How to Run Locally

### 1. Backend Setup
```bash
cd Ecommerce_Backend
npm install
npm run build
npm start
```
*Backend runs on `http://localhost:4000`.*

### 2. Frontend Setup
```bash
cd Ecommerce_Frontend_React
npm install
npm run dev
```
*Frontend runs on `http://localhost:5173`.*

##  Testing the Output

1. Open [https://apexstore-frontend-two.vercel.app/](https://apexstore-frontend-two.vercel.app/) in your browser.
2. Add products to the **Cart** or **Wishlist**.
3. Use the **Search** and **Filter** options.
4. Navigate to `/admin/dashboard` to view the admin controls and order statuses.
